# Cases deliberately excluded from the ceph/s3-tests conformance run.
#
# Two kinds of line, both ending in `# reason`:
#
#   marker:name                 a pytest marker; feeds -m "not name and ..."
#   suite/path.py::test_name    a single node id; feeds --deselect
#
# Either way the case is recorded as SKIP in the manifest, never dropped --
# pytest_deselected in predastore_cleanup.py catches everything -m and
# --deselect filter out and writes it to the manifest itself, so a skip here
# is still visible in the count and the line is never lost.
#
# The bar for a line here is high, and it is not "predastore fails this".
# An operation that is unimplemented but wanted must stay a FAIL: that is
# the gap the manifest exists to show, and skipping it hides the thing being
# measured. The question a line here has to answer is not "does this fail"
# but "is anyone going to fix this soon" -- a case with an open bead actively
# being worked stays a FAIL so the baseline shows it flip to PASS when the fix
# lands. A line belongs here only when predastore has decided not to offer the
# feature for now, or the case cannot report anything useful on its own (e.g.
# it takes the run down rather than failing).
#
# Whole test modules are excluded in scripts/s3-tests.sh instead, by not being
# in SUITES: test_iam, test_sts, test_sns, test_s3select and test_s3control
# cover RGW extensions and other AWS services, none of which predastore claims.
